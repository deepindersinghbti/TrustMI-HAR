# TrustMI-HAR progress, 25 Sep 2026: Phase E (literature baselines TMC and ECML)

## What we did, in order
1. **Got the official code of both methods** (TMC, ICLR 2021; ECML, AAAI 2024) into ~/ext, outside the project.
   Neither repository has a licence, so no code was copied. Versions checked against: ECML/RCML c9c5ab4, TMC a3272b8.
2. **Re-implemented both from the papers** (src/trustmi/models/evidential.py) and proved them identical to the
   official code on random inputs: fusion identical, loss within 1.5e-7 (float rounding). Verdict: EQUIVALENT.
3. **Added them to train.py** (tmc, ecml; tmc_s, ecml_s for MMAct). Each sensor uses the same network as our
   single-sensor experts; training follows our shared protocol (60 epochs, early stopping on validation macro-F1,
   KL phase-in = 10% of epochs, as in the papers). Smoke tests passed (8/8).
4. **UTD-MHAD, 48 runs (8 people x 3 seeds x 2 methods).** Clean accuracy: B4 95.0%, TMC 94.4%, ECML 93.5%.
   Comparable: 8 people are too few to call B4 better.
5. **Problem: an automatic Ubuntu update replaced the NVIDIA driver mid-run.** The GPU vanished, 29 MMAct runs
   crashed, and a reboot restored the GPU. The automatic-restart entry relaunched the job, which redid only the
   missing runs (results are written atomically, so none were damaged). Fix: driver and kernel packages are now
   excluded from automatic updates (/etc/apt/apt.conf.d/50unattended-upgrades; backup .bak-2026-09-25).
6. **Collected TMC/ECML trust signals on exactly the same planted lies as our certificate** (scripts/cert_evidential.py).
   Their uncertainty u barely reacts to lies (ECML AUROC 0.500): the lying sensor is a real, confident recording,
   and ECML's averaged evidence ignores whether sensors agree. ECML's conflict measure does react (0.72, rough).
7. **Fairness check:** retrained with the papers' own optimiser settings (tmc_p, ecml_p). TMC was unchanged
   (same evidence ceiling ~12); ECML got worse (clean 90.2%, lie detection 0.642, naming 59.5%). The rule fixed in
   advance (pick each method's version by validation lie detection) kept our protocol for both
   (TMC 0.843 vs 0.840; ECML 0.848 vs 0.790).
8. **Scored side by side, UTD-MHAD** (scripts/cert_evidential_score.py; per test person, fitted on validation):

   | | Catch lies (AUROC) | Name the liar | Lie clips, rev 1 | Lie clips, rev 2 | Normal, rev 2 |
   |---|---|---|---|---|---|
   | Our certificate | **0.873** | **83.1%** | 72.9% | 70.5% | 94.9% |
   | TMC | 0.842 | 74.1% | **74.9%** | **74.9%** | 94.4% |
   | ECML | 0.832 | 67.0% | 69.1% | 69.3% | 92.8% |

   - Ours catches lies better than both for all 8 people (+0.031 vs TMC, +0.040 vs ECML; 95% intervals above 0)
     and names the liar better (+9.0 and +16.1 points, 8/8).
   - TMC matches or beats us on final accuracy on lie clips (not significant with 8 people).
   - Reason: before any policy, B4 gets only 60.9% on lie clips (TMC 74.9%, ECML 65.3%). Cross-attention
     lets one lying sensor mislead the whole model. Our certificate recovers most of that gap, not all.
9. **MMAct, 120 runs (20 people x 3 seeds x 2 methods)** finished at 19:05, no failures.
